Расшифровка строк журнала

Код режима (ret= и modWork:, шестнадцатеричное число): биты складываются. 01 - отопление, 02 - охлаждение, 04 - ГВС, 08 - разморозка, 80 - «продолжение» (режим уже идёт, без нового пуска), 00 - выключено. Примеры: 1 - отопление (старт), 81 - отопление, продолжение, 84 - ГВС, продолжение.

Точка возврата (Hp11, Bp12, [Hp2] и т. п.): три поля <источник><алгоритм><номер>. Источник: B - бойлер (ГВС), H - отопление, C - охлаждение. Алгоритм: h - гистерезис, p - ПИД. Особые значения: none - в начале, решения ещё нет; MinPause - ждём минимальную паузу между включениями; Bdis - сброс тепла (слив бойлера); Bgen - запрет на генераторе. Пример: Bp12 - бойлер, ПИД, «дошли до ПИДа, регулируем».

Строки журнала

  • EvaluateWorkMode: Hp11, ret=81 (флаг MODW): решение алгоритма на этом проходе. Hp11 - точка возврата (отопление, ПИД, «время ПИДа не пришло»); ret=81 - код режима (отопление, продолжение).
  • EvaluateWorkMode-Boiler: none(Hp11), ret=0, onBoiler=0, flagRBOILER=1 (флаг MODW): решение для ГВС. Формат <текущая точка>(<предыдущая>); ret - код режима (0 - ГВС не нужен); onBoiler - 1, если ТН сейчас греет бойлер (не ТЭНом); flagRBOILER - 1, если идёт или скоро может пойти цикл догрева бойлера ТЭНом (бойлер ниже гистерезиса).
  • Start modWork:1[Hp2]: начало режима работы. 1 - код режима (отопление), в скобках точка возврата (Hp2 - включение по гистерезису).
  • modWork:81[Hp11] RCOMP:1 RPUMPI:1 … freqFC:55.00 Power:1.250 EEV:480 … (флаг DUMP): строка состояния ТН. После кода режима и точки возврата идут реле (имя:1 - включено, 0 - выключено), freqFC - частота инвертора, Гц, Power - мощность инвертора, кВт, EEV - положение ЭРВ, затем входы (имя:состояние контакта). Вторая строка - температуры, °C, и датчики давления.
  • Pumps(1), modWork: 1, compressorON > modWork:…: переключение насосов и включение компрессора, после них показан текущий код режима.
