Описание расписания НК


Расписание - в НК встроена работа по расписанию на неделю. Возможна установка изменений с точностью до 1 часа.
Работа расписания базируется на профилях, фактически расписание это таблица применения профилей по часам и дням недели. Для эффективного использования расписаний необходимо в начале создать требуемые профили. Помимо переключения между профилями возможна постановка ТН на паузу (ТН выключен) и добавка к целевой температуре(±Температура). Все варианты действий по расписанию отображены на рисунке (с номерами это профиля).

Временно можно выбрать любое расписание, которое будет действовать до прихода времени очередного. Если все таки нужно временно использовать заданные вручную настройки и чтобы сохранить автоматизм - можно выбрать расписание, в котором установлено на все время "± Температура" равная 0.
Работа по расписанию (переключатель в заголовке карточки «Расписания») - включение работы по расписанию НК. При включении этой опции в шапке вместо профиля работает расписание.
Список расписаний - чипы с номерами и именами. НК содержит до 5 независимых расписаний. Нажатие на чип открывает расписание для редактирования; расписание, которое сейчас работает на контроллере, помечено «активно».
Имя расписания - можно изменить в поле (до 31 байта, около 15 русских букв).
Автовыбор расписания (0 - нет) - месяц и декада (1 - числа 1-10, 2 - 11-20, 3 - с 21 до конца месяца), в которые расписание включается само. Выбор делается один раз: если в эту декаду вручную выбрать другое расписание, автовыбор его не отменит до следующего года. Для этого должна быть включена «Работа по расписанию». Служит для переключения между расписаниями по времени года.
Сейчас - что работает по расписанию в этот момент и когда будет следующее изменение. Кнопка Сделать активным (появляется, если открыто не активное расписание) включает открытое расписание на контроллере.
Календарь - таблица 7 суток по 24 часа, в клетках действие на этот час. Порядок создания/изменения расписания:
- выбрать действие-«кисть» над таблицей: «ТН выключен», «± температура» (число в поле, от −10 до +12,5 °C), «не менять» или один из профилей (номер и имя профиля);
- нажав левую кнопку мыши, выделить на клетках таблицы время выбранного действия (прямоугольником);
- для стирания клеток нажать Shift (или правую кнопку) и выделить стираемые клетки; на телефоне - касанием.
Чтобы текущий профиль не менялся, нужно заполнить «± температурой», равной 0, либо «не менять».
Применить отправляет календарь на ТН. Кнопки в нижней части: Считать из EEPROM - заменить расписания сохранёнными в памяти (несохранённые правки пропадут), Записать только расписание - записать только расписания в EEPROM, Очистить все календари… - стереть все 5 календарей. Общая кнопка «Записать в EEPROM» сохраняет расписания вместе с профилями и настройками.
