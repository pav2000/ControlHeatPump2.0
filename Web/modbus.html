Подсказки. Для корректного отображения информации из регистра необходимо правильно указать формат хранимого значения в регистре (см. документацию на устройство). Нумерация адресов параметров ведётся согласно документации, обычно с нуля, кроме частотника — он с единицы. Для ввода в шестнадцатеричном формате нужно спереди добавить «0x». Например: прочитать напряжение счётчика SDMхxx — установить адрес устройства на шине 2, добавить строку вывода, нажав кнопку I (float), ввести параметр, равный 0, и прочитать регистр, нажав кнопку «›». Запись (строки H, I, C) просит подтверждения.
