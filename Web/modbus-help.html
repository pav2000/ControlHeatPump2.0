Описание страницы «Диагностика → Modbus»

Прямое чтение и (осторожно!) запись регистров устройств на шине RS-485: частотного преобразователя (адрес 1) и электросчётчика (адрес 2). Инструмент для опытных пользователей и специалистов.

  1. Задайте адрес устройства на шине.
  2. Добавьте строку кнопкой нужного типа. Чтение (адреса с 4…, входные регистры): W — 16 бит, L — 32 бита, F — float. Запись (адреса с 3…, регистры хранения): H — 16 бит, I — float, C — coil. Строки записи тоже можно прочитать кнопкой «›».
  3. Укажите адрес параметра (по документации устройства; обычно нумерация с нуля, у частотного преобразователя — с единицы; для шестнадцатеричного ввода добавьте 0x) и нажмите «›», чтобы прочитать значение.

В таблице «Регистры» для каждой строки показаны устройство, тип, параметр, значение, его 0x-представление и статус обмена. Правильно указывайте формат хранимого значения — иначе данные будут показаны неверно.

Автообновление опрашивает строки по очереди, по одной (шина читает регистры последовательно); строки с адресом 0 не опрашиваются.

Пример: чтобы прочитать напряжение счётчика SDM, установите адрес устройства 2, добавьте строку чтения F (float), введите параметр 0 и нажмите «›».

Осторожно: запись (H, I, C) просит подтверждения; неверные значения могут нарушить работу преобразователя или счётчика.
